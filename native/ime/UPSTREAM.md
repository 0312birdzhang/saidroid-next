# Maliit peer protocol

The interface XML files come from [maliit/framework](https://github.com/maliit/framework/tree/ba6f7eda338a913f2c339eada3f0382e04f7dd67). The upstream LGPL 2.1 license is included as LICENSE.LGPL.

SailDroid connects as the current ordinary user to the existing peer socket. It does not install or restart the system input method.
